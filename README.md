# App Store IPA Creator

GitHub Pages + GitHub Codespaces-ready web app example for creating and previewing iOS IPA archive information.

## Features

- Enter App Store IPA information
- Live App Information preview
- Create IPA package button
- Displays:
  - App Name
  - Bundle ID
  - Version
  - Platform
  - Minimum OS
  - IPA File
  - File Size
  - App Bundle Path
  - Archive Type
